MarkSpec Config Schemas

JSON Schemas for MarkSpec configuration files. Reference one from a config file's $schema key for editor validation and autocomplete.

project/v1.json The project.yaml project manifest — name, version, labels, parents, caption conventions. markspec/v1.json The .markspec.yaml consumer binding — activated profile chain and default-profile opt-out. profile/v1.json A profile's markspec.yaml manifest — id, version, extends chain, type and attribute declarations. lock/v1.json The markspec.lock lockfile — upstream version pins, sync mappings, and the per-edge identity ledger. ← MarkSpec documentation
